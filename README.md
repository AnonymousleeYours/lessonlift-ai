# LessonLift AI

LessonLift helps Indian school teachers create, review, edit, save, and export curriculum-aligned teaching resources.

## Planned features
- 5E-model lesson plans
- Board, class, subject, chapter, and topic selection
- English, Hindi, and bilingual resources
- Notes, quizzes, worksheets, assignments, projects, and teaching-learning materials
- Differentiated and slow-paced learning options
- Teacher library and PDF/DOCX export

These are planned capabilities, not claims that the features are already implemented.
